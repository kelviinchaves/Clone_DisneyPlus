# 📖 Sobre o projeto

O objetivo deste projeto foi reproduzir a interface da página inicial do Disney+, colocando em prática conceitos essenciais do desenvolvimento Front-end.

Durante o desenvolvimento foram trabalhados conceitos como:

- Estruturação semântica utilizando HTML5;
- Organização dos estilos com Sass;
- Modularização dos arquivos SCSS;
- Automatização de tarefas utilizando Gulp;
- Manipulação do DOM com JavaScript;
- Layout responsivo para diferentes dispositivos.

Este projeto possui finalidade exclusivamente educacional.

Todos os direitos relacionados à marca Disney+ pertencem à The Walt Disney Company.

# 💻 Como executar o projeto

Clone o repositório

```bash
git clone https://github.com/kelviinchaves/Clone_DisneyPlus.git
```

Entre na pasta

```bash
cd Clone_DisneyPlus
```

Instale as dependências

```bash
npm install
```

Execute o Gulp

```bash
npm run gulp
```

Abra o navegador em

```
http://localhost:3000
```
